Predicting Student Test Scores — Kaggle Competition

This project focuses on predicting student exam scores using machine learning techniques. The dataset comes from the Kaggle competition Playground Series - Season 6 Episode 1 and the task is a regression problem, where the target variable is the student’s exam score ranging from 0 to 100.

The first notebook, pred_score_eda.ipynb, contains:

- Exploratory Data Analysis (EDA)
- Data preprocessing
- Feature analysis
- Basic model training and evaluation

The main purpose of this notebook is to:

- Understand the dataset structure and relationships between variables
- Identify important features affecting student performance
- Perform initial preprocessing and cleaning
- Train baseline regression models
- Evaluate model performance using standard regression metrics

This notebook serves as the foundation for further model improvement, feature engineering, and hyperparameter tuning in later stages of the project.
